# Mini Application - TODO List (Laravel 10)

Aplikasi web sederhana TODO List dibangun menggunakan modern framework **Laravel 10**, **Bootstrap 5**, dan **MySQL**.

## Fitur Utama
1. **Create New Todo**: Menambahkan tugas baru ke dalam sistem.
2. **Update Status Todo**: Menandai tugas sebagai selesai atau belum selesai.
3. **Delete Todo**: Menghapus tugas dari daftar.
4. **Database Integration**: Seluruh data tersimpan secara terintegrasi di database MySQL.

## Persyaratan Sistem
- PHP >= 8.1
- Composer
- MySQL Database (Laragon / XAMPP)
